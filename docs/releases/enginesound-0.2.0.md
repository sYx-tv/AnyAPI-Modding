# EngineSound 0.2.0

EngineSound is a new mod that replaces the three stock engine sounds with a much wider choice. Open an engine with the Properties Tool and move the **Sound effect** slider past the stock sounds: 3-9 are presets (Muscle V8, Smooth inline, Tamed sport, Big diesel, Built 2JZ, Powerstroke, Hemi) and 10 is **Custom**.

Custom has twelve sliders: engine type (16 inline, V, boxer, diesel, rotary and electric characters), idle pitch, rev range, rev curve, volume, body layer, cam lope, induction (turbo, supercharger or twin turbo), boost noise, lift-off crackle, throttle response and rev smoothing. **Customize this sound** copies any preset or stock sound into Custom as a starting point.

The choice is stored in the engine's own sound setting, so it is saved with the vehicle and every player with EngineSound hears the same engine in co-op. The host must run EngineSound for the new values to be selectable. EngineSound uses the experimental SDK and only activates on Anymaker 0.1.23 / Steam build 25755694. Guide: [EngineSound](../mods/engine-sound.md).

The parameter tests passed on Windows, and the author confirmed the presets and Custom sliders in game before release.
