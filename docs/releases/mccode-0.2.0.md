# MCCode 0.2.0

**Nodes: build microcontroller programs from boxes and wires.** Press **Nodes** in the Code view's toolbar for a
Stormworks-style canvas next to the typed code and the game's blocks.

- **43 nodes** in seven groups: part inputs and outputs, numbers and on/off values, maths, compares, logic,
  memory (latch, toggle, pulse, counter), timers and blinkers, and control (ramp, smooth, PID).
- **Wire by dragging** from an output to an input. Blue wires carry numbers, green wires carry on/off.
- **Apply** turns the graph into the game's blocks, exactly like typed code, so saving, multiplayer and players
  without the mod work as usual.
- **Live values** show on each output while the program runs.
- **Saved in the program:** a node program reopens as nodes, and problems are shown on the node they belong to.

Anymaker 0.1.25 only; needs AnyAPI 0.38.0 or newer. See [MCCode](../mods/mccode.md#nodes).
