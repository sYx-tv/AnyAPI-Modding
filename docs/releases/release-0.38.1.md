# AnyAPI 0.38.1

For Anymaker 0.1.25 (Steam build 25904830). Update in the manager, then restart the game.

## AnyAPI 0.38.1

- **Pictures for modded parts.** Parts that mods add to a loaded world (GpsPart's GPS Sensor, AnyEngineParts' turbos,
  superchargers, Dyno and Rotary) now show a picture in AnyInventory's item browser and AnyQuickWheel, drawn from their
  model like the game's own parts. The catalog's generated record for a mod-added component now carries its
  `mesh_static` path. They had no picture before.
- No service changes; mods need no update for this.

AnyEngineParts 0.2.0 ships in the same round; see [its notes](anyengineparts-0.2.0.md).
