# AnyAPI Manager 1.3.1

Bundles the validated AnyAPI 0.27.0 release for Anymaker 0.1.23 and the matching
25-header, 100-article developer guide. All five optional mods are available as
independent downloads; no optional mod DLLs are bundled in the EXE.

Settings supports verified manager EXE updates, with backup and rollback. Existing
1.3.0 users can choose Check for updates, then Update & restart.

All 93 manager fixture checks pass, including the updated API payload, installation
rollback, launch modes, local mods, developer export and EXE replacement. Preview
metadata now follows the bundled release instead of a hardcoded older version.
