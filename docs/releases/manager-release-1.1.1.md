# AnyAPI Manager 1.1.1

The mod library is now public and built into the manager. Browse and install without a GitHub account, GitHub CLI, or entering a repository address.

- Removed repository setup fields and private-download authentication fallback.
- Older saved repository addresses are replaced by the built-in library address; your game folder and installed mods remain unchanged.
- Settings offers Refresh library and View on GitHub.
- Includes API revision 25, launch modes, offline developer guide and source-only starter SDK. Optional mods remain separate downloads.

Validated 54 automated checks and 7 anonymous HTTPS catalog/package checks. Game files were not changed. AnyGraphics development is paused and is not included in this release.

Download AnyAPI.Manager.exe or extract AnyAPI-Manager-1.1.1.zip. Replace your previous manager EXE with this version.
