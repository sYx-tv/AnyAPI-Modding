# Complete supplied SDK references

These are the complete supplied reverse-engineering reference bundles, including metadata, generated documentation, layouts, analysis tools, examples, and (where supplied) validation evidence and build comparison reports. Only Python bytecode caches are excluded.

The original folder was named `decompile`, but both bundles explicitly contain **no decompiled function bodies**. These downloads do not contain game executables or assets. The original and v2 references describe different game builds; check their build identities before using addresses.

- [Anymaker-Decompile-Reference-Original.zip](https://github.com/sYx-tv/AnyAPI-Modding/releases/download/sdk-reference-2026.10.08/Anymaker-Decompile-Reference-Original.zip): 2116 files. [File manifest](Anymaker-Decompile-Reference-Original.manifest.json).
- [Anymaker-Decompile-Reference-v2.zip](https://github.com/sYx-tv/AnyAPI-Modding/releases/download/sdk-reference-2026.10.08/Anymaker-Decompile-Reference-v2.zip): 969 files. [File manifest](Anymaker-Decompile-Reference-v2.manifest.json).

The v2 bundle is the newer reference, for Steam build 25755694. The original is retained for historical comparison.

For AnyAPI integration and guarded bindings, start with the [experimental SDK](../../sdk/experimental/README.md). These archives preserve the supplied research, including its limitations; they are not a claim that every discovered function has been called successfully.
