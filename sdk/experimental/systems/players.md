# Players, characters, health, abilities and interaction

> Generated by `tools/sdk_systems.py` from `tools/systems_spec.py` and `json/` for Steam build 25826614. Function lists are complete for the key functions only; search `json/sdk_index.sqlite` for the rest.

**Object graph.** A connected player is a server_peer (network) + server_scene.peer (scene data) + an actor in server_scene.m_actors whose authority belongs to that peer. The local player on a client is client_scene.actor.container.get_peer_actor.

**Client/server.** Damage, abilities, inventory and authority are server-side. Interaction starts on the client (client_scene.actor_interactions) and is applied by server_scene.*.interact_begin/end.

**Threads.** Server thread for server_scene.actor*; main thread for client_scene.actor*.

_Classification evidence: side and thread tags are static (namespace, source path, call-graph reachability); see each function's side_basis._

| Register a new definition or implementation | **closed** | Abilities and actor classes are fixed gcl code paths; new ones need new gcl types. |
